# .agents Configuration Directory

This directory contains the central instructions, technical context, and multi-agent collaboration rules for **DYAD**.

* **Primary Document:** [`context.md`](./context.md) — Must be read by all AI coding assistants (Cursor, Windsurf, Claude Code, Antigravity, Copilot, Cline, Aider, etc.).
* **Design Craft & System:** [`design-system.md`](./design-system.md) — Impeccable tokens, Emil Kowalski spring physics, Taste guidelines, and Watermelon UI standards.
* **Key Rule:** All prototyping must occur in isolated, descriptive subfolders (e.g., `prototype-agent-orchestration/`, `prototype-datasets-collection/`, `prototype-modal-cloud-experiments/`, `prototype-map-canvas-ui/`) to ensure zero git merge conflicts across teammates.
